# Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities privately through the affected repository's **Security → Advisories → Report a vulnerability** form. Do not include vulnerability details in public issues or pull requests.

If the repository has no reporting option, use the [organisation's private reporting form](https://github.com/woodleighschool/.github/security/advisories/new). Include the affected repository, version or commit, steps to reproduce the problem, and its potential impact. Do not include passwords, tokens, or personal data.

The maintainer will review the report and discuss it with you privately. Any public advisory will be coordinated with you, including the fix or available mitigation.
